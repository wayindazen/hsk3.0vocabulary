HSK 3.0 词汇 — Карточки для изучения китайского языка
Веб-приложение для эффективного запоминания слов из нового стандарта HSK (уровни 1–9).

🚀 Основные функции
Интерактивные карточки: Нажмите на иероглиф, чтобы открыть произношение (пиньинь) и перевод.
Озвучка: Прослушивание правильного произношения с помощью синтеза речи (TTS).
Режим Квиза: Проверьте свои знания, вписывая иероглифы по памяти.
Примеры из Tatoeba: Быстрый поиск живых примеров предложений на китайском с переводом.
AI Помощник: Быстрый переход в Google для глубокого разбора слова.

🛠 Технологии
HTML5 / CSS3 (Адаптивный дизайн, работает на мобильных устройствах).
Vanilla JavaScript (Без тяжелых библиотек).
Web Speech API для озвучки.

📖 Как использовать
Выберите уровень HSK в выпадающем списке.
Нажимайте на карточку для проверки перевода.
Используйте кнопку "Следующее слово" для тренировки.
Перейдите в режим "Квиз", чтобы закрепить навык написания.
